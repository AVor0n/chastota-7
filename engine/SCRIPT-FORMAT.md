# Формат сценария «Частота 7»

Версия 1 (2026-10-01). Владелец формата: тред «Движок игры». Если чего-то не хватает, напишите координатору, движок допишем; сами синтаксис не придумывайте, иначе проверка его не поймёт.

Проверка сценария: `node /mnt/project-files/game/tools/check.mjs` (появится в ближайшее время). Она находит ошибки разметки, битые переходы, тупики, недостижимые узлы и прогоняет все ветки до концовок.

## Где что лежит

```
story/script/
  setup.md        персонажи, переменные, предметы, концовки, стартовый узел
  scenes/*.md     сами сцены (узлы), файлов сколько угодно, порядок не важен
  images.md       описание каждой картинки для художника (или images/*.md)
  docs.md         тексты находок: страницы журнала, письма, записи кассет (или docs/*.md)
  minigames.md    описание мини-игр (что видит игрок, условие успеха)
```

`images.md` и `docs.md` можно разбить на несколько файлов в папках `images/` и `docs/`: читаются все `.md` оттуда вместе с основным файлом, один id описывается только один раз.

Всё в UTF-8. Строка, начинающаяся с `//`, это комментарий для авторов и критиков, игрок его не видит. Идентификаторы (`id`) пишутся латиницей: буквы, цифры, `_`.

## setup.md

```
start = koster_intro

## персонажи
// id | имя на экране | заметка (по желанию)
tim   | Тим
asya  | Ася
leva  | Лёва
vera  | Вера  | radio
hero  | Ты

## переменные
// id = значение по умолчанию | комментарий
tim_trust = 0       | доверие Тима, от -3 до 3
asya_trust = 0
fire_out = false

## память
// эти переменные НЕ сбрасываются между прохождениями
heard_cassette = false

## предметы (рюкзак: 6)
// id | название | описание в рюкзаке
radio    | Приёмник Тима   | Коробка из-под конфет, внутри провода и лампа.
flashlight | Фонарик       | Батарейка садится, если светить долго.

## концовки
// id | название на экране | одна строка под названием
dawn     | Рассвет         | Утро всё-таки кончилось.
```

- Если описание предмета начинается с `(карман)`, например `kurgod | Куриный бог | (карман) Камешек с дыркой.`, предмет не занимает место в рюкзаке и окно «что оставить» не вызывает. `has()` работает как обычно, в рюкзаке он показан отдельно, «в кармане».
- Число в `(рюкзак: 6)` задаёт размер рюкзака. Когда он полон и герой берёт ещё вещь, игра сама спросит, что оставить; оставить можно и новую вещь. Поэтому `has(id)` всегда говорит правду, а не то, что задумал автор.
- Пометка `radio` у персонажа значит, что его реплики звучат «из эфира»: другой шрифт и помехи. Отдельную реплику любого персонажа можно пустить через эфир ремаркой со словами «в эфире»: `Вера (в эфире): Я иду.`

## Сцены: узлы

Сцена состоит из узлов. Узел начинается заголовком `# id` и идёт до следующего заголовка. Игрок проходит узел построчно: **одна непустая строка = один экран текста**, следующая появляется по касанию. Держите строку до ~200 знаков; длиннее проверка предупредит.

Каждый узел заканчивается одним из трёх: блоком выборов, переходом `-> id` или концовкой `@ending id`. Узел без выхода считается тупиком и ломает проверку.

```
# koster_intro
@chapter 1 Костёр
@image koster_night
@anim fire at=41%,79% ; water below=70% ; stars
@music night_1
@radio 0.2

Озеро тянет холодом, а от костра горячо щекам.
Тим (не поднимая головы): Ещё минуту. Я почти поймал.
Ася: Ты это говоришь третий час.
_Приёмник щёлкает, и шум становится другим._

* "Дай мне покрутить." {tim_trust -= 1} -> koster_tune
* Подбросить веток в огонь -> koster_wood
* [if asya_trust >= 1] Шепнуть Асе, что пора спать -> koster_sleep
```

### Строки текста

| Запись | Что видит игрок |
|---|---|
| `Обычный текст.` | Текст рассказчика (второе лицо, «ты»). |
| `Тим: Реплика.` | Реплика с именем. Имя должно быть объявлено в `setup.md`. |
| `Тим (шёпотом): Реплика.` | То же, ремарка мелко под именем. |
| `> Мысль героя.` | Внутренний голос героя, курсивом без имени. |
| `_слово_` | Курсив внутри любой строки. |
| `[пошёл\|пошла]` | Вариант по полу героя: первый для внука, второй для внучки. Работает в любом тексте: строки, реплики, выборы, находки, `@toast`. Выбирается переменной `hero_f` (`false` внук, `true` внучка); объявите её в `setup.md`, ставится обычным эффектом `{hero_f = true}`. |

### Выборы

```
* [условие] [once] Текст выбора {эффекты} -> цель
```

- Блок выборов стоит в конце узла, от 1 до 4 строк подряд.
- Текст в кавычках `"..."` это реплика: после выбора она показывается как слова героя. Без кавычек это действие, оно не повторяется.
- `[if условие]` прячет выбор, если условие ложно.
- `[need условие]` показывает выбор зачёркнутым карандашом, если условие ложно: игрок видит, что путь был, но сейчас закрыт. Хорошо для повторного прохождения.
- `[once]` убирает выбор после того, как его выбрали (для узлов-«комнат», куда возвращаются осматривать вещи). Если все выборы узла исчезли, проверка сочтёт это тупиком, оставляйте выход без `[once]`.
- `[key]` помечает ключевой выбор: звонкий звук при касании (см. `@key` ниже).
- `[spot имя]` помечает выбор как место на картинке (шкаф, комод). Пока это обычная кнопка; когда картинка будет нарисована, движок может сделать на ней зону касания. На смысл не влияет.
- `{эффекты}` выполняются при выборе, через `;`, так же как строки `~` ниже.
- Все выборы необратимы, игра сохраняется сама после каждого.

Таймер выбора (для напряжённых моментов, не чаще пары раз за игру):

```
@timer 6 -> leva_falls
* Схватить Лёву за руку -> leva_saved
* Крикнуть Асе -> asya_runs
```

Если игрок не выбрал за 6 секунд, игра идёт в `leva_falls`.

Ключевой выбор (1–3 на всю игру, где решение правда меняет историю):

```
@key
* Остаться ещё на одно утро -> stay
* Уплыть сейчас -> leave
```

`@key` стоит прямо перед блоком выборов (можно вместе с `@timer`, в любом порядке). При касании любого выбора этого блока звучит звонкий звук `sfx/ui_choice_key`, у обычных выборов звук глухой (`sfx/ui_choice`). Пометить один выбор, а не весь блок: `* [key] Текст -> цель`. На ход игры пометка не влияет.

### Переходы и условия

```
-> id                  перейти в узел
~ tim_trust += 1       изменить переменную (=, +=, -=)
~ fire_out = true
~ take photo           положить предмет в рюкзак
~ drop knife           выложить/потерять предмет
[if has(knife)] Ася: Отдай нож.     условие на одну строку (любую: текст, ~, @, ->)

@if tim_trust >= 2 and has(radio)
Тим: Держи. Только не урони.
@elif tim_trust < 0
Тим молча отворачивается.
@else
Тим пожимает плечами.
@end
```

Условия: числа, `true`/`false`, переменные, `== != < <= > >=`, `and or not`, скобки, `+ -`. Функции:

| Функция | Значение |
|---|---|
| `has(id)` | предмет сейчас в рюкзаке |
| `seen(id)` | узел уже был в этом прохождении |
| `ever(id)` | узел был хоть в одном прохождении |
| `read(id)` | находку из `docs.md` уже открывали в этом прохождении |
| `ending(id)` | эта концовка уже была когда-то |
| `run` | номер прохождения: 1, 2, 3… |

## Картинка, движение, звук

Всё это строки `@...` внутри узла, в том месте, где должно сработать.

### Картинка и камера

| Запись | Что делает |
|---|---|
| `@image id` | Сменить кадр плавным наплывом. Кадр держится, пока его не сменят. |
| `@image id cut` | Сменить резко (испуг, удар). |
| `@image id slow` | Медленный наплыв, ~3 с, как в диафильме. |
| `@black` | Тёмный экран, текст на тёмном (сон, темнота пещеры). |
| `@pan left` / `right` / `up` / `down` / `in` / `out` | Медленный проезд камеры по кадру, пока кадр на экране. |
| `@focus 30%,62% 1.8` | Медленно приблизить точку кадра (x%, y%) с увеличением 1.8. `@focus off` вернуть. |
| `@shake` | Короткая тряска. |
| `@flash` | Короткая белая вспышка. |
| `@text top` / `bottom` | Где стоит текст на этом кадре (по умолчанию внизу). Действует до смены кадра: `@image` и `@black` возвращают текст вниз. |
| `@video id` | Вставка-видео (только спокойные, из kie.ai). Использовать редко. |

`@anim` оживляет кадр кодом, без видео. Эффекты через `;`, можно несколько:

| Эффект | Что это |
|---|---|
| `fire at=x%,y%` | Мерцание света и искры от огня в точке. |
| `lamp at=x%,y%` | Тёплое дрожание лампы или свечи. |
| `water below=y%` | Рябь воды ниже линии y. Можно сузить по ширине: `water below=70% x=10%..90%`, или задать прямоугольник: `water rect=x%,y%,ш%,в%` (левый верхний угол, ширина, высота). Люди и лодки в воде не должны попадать в область, иначе их «плавит». |
| `fog` | Туман медленно ползёт по кадру. `fog dense` гуще. |
| `stars` | Звёзды мерцают в тёмном небе. |
| `wind` | Ветер в ветках и траве (лёгкое колыхание краёв кадра). |
| `dust` | Пылинки в луче света. Видны только на тёмном, поэтому их лучше собрать в тёмную часть кадра: `dust rect=x%,y%,ш%,в%` (левый верхний угол, ширина, высота). |
| `fireflies` | Светлячки. |
| `rain` | Дождь. |
| `glitch` | Помехи по кадру, как сбитый сигнал. Для странных моментов. |
| `beacon at=x%,y%` | Красный огонь маяка: медленно разгорается и гаснет раз в ~3,5 с. `beacon at=x%,y% morse` мигает «7» азбукой Морзе. Единственный красный в кадре. |
| `still` | Ничего не двигается вообще, даже зерно (тревожная тишина). |

Без `@anim` у кадра остаются только зерно бумаги и лёгкое «дыхание», как у диафильма. Новый `@image` сбрасывает эффекты, после него пишите `@anim` заново.

### Звук

Звуковые id соответствуют файлам в `/mnt/project-files/audio/` (музыка `music/<id>.mp3`, фоны `amb/<id>.mp3`, звуки `sfx/<id>.mp3`). Список готовых звуков ведёт тред «Музыка и звуки»; если нужного ещё нет, всё равно пишите id, проверка покажет список недостающих.

| Запись | Что делает |
|---|---|
| `@music id` | Фоновая музыка, по кругу, с плавным переходом. `@music stop` выключить. `fade=6` задаёт длину перехода в секундах (по умолчанию 2.5): `@music theme fade=6`, `@music stop fade=8`. |
| `@amb id` | Фон окружения (лес, вода, пещера), второй слой под музыкой. `@amb stop`. `fade=` работает так же, как у `@music`. |
| `@sfx id` | Один звук (скрип двери, лай). |
| `@radio 0.4` | Шум эфира, синтезируется кодом, от 0 до 1. `@radio 0` выключить. |
| `@silence` | Резко выключить всё (музыку, фон, эфир). |
| `@vibrate` | Короткая вибрация (только Android, если включена). |

### Прочее

| Запись | Что делает |
|---|---|
| `@chapter 2 Остров` | Карточка главы на тёмном, карандашом. |
| `@wait 2` | Пауза 2 секунды без текста. |
| `@toast Тим это запомнит.` | Короткая надпись в углу, не останавливает игру. |
| `@doc id` | Показать находку из `docs.md` на листе бумаги. Она попадает в «Находки», их можно перечитать из рюкзака. |
| `@game id param=знач -> ok:узел, fail:узел` | Мини-игра (см. ниже). |
| `@ending id` | Концовка из `setup.md`. Партия кончается, сохранение очищается, номер прохождения растёт. |

## images.md

Для каждого `@image id` нужен блок описания. Это задание художнику.

```
# koster_night
Ночь, костёр на берегу, трое подростков и младший мальчик со спины, приёмник на бревне.
Свет: только огонь и луна. Пустое тёмное небо сверху под текст.
Движение: fire at=41%,79%; water below=70%; stars
```

Файл картинки потом ляжет в `art/scenes/<id>.jpg` (9:16). Одна картинка может использоваться в разных узлах.

## docs.md

```
# doc journal_p3 | Журнал станции, страница 3
Текст находки. Пустая строка делает новый абзац.

Можно несколько абзацев. _Курсив_ работает.
```

Вид листа задаётся по id: начинается на `journal` — линованный журнал, `letter` — письмо от руки, `tape` — расшифровка кассеты, иначе обычный лист.

## minigames.md

```
# game tuner | Настройка приёмника
Что видит игрок, что делает пальцами, когда успех, когда неудача, сколько попыток.
Параметры: target (номер частоты).
Исходы: ok, fail.
```

В сценарии игра вызывается так: `@game tuner target=7 -> ok:tune_ok, fail:tune_fail`. Каждый исход из описания должен вести в узел. Мини-игры движок делает по этим описаниям, новые типы отправляйте координатору.

## Что проверяет check.mjs

- разметку каждой строки, неизвестные `@`-команды, персонажей, переменные, предметы;
- что все `-> цель` существуют, у каждого узла есть выход, все узлы достижимы со старта;
- полный перебор веток: до каждой ли концовки можно дойти, нет ли зацикливаний и узлов, где игрок застревает;
- что у каждой картинки, находки и мини-игры есть описание; список недостающих файлов картинок и звуков.
