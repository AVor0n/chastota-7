# Частота 7

Текстовый квест для браузера на телефоне. Упор на сюжет, таинственность и исследование; карандашные рисунки, живые кадры на WebGL, музыка, фоны и голоса из эфира.

Игра рассчитана только на мобильный экран. На компьютере она просит открыть ссылку на телефоне. Звук включается после первого касания; лучше играть в наушниках.

## Как запустить

Готовая сборка лежит в папке `game/`. Её нужно открыть через любой локальный веб-сервер (просто двойной клик по `index.html` не подойдёт: браузер не даст загрузить звук):

```
cd game
python3 -m http.server 8000
```

Дальше:

- **на телефоне**: телефон и компьютер в одной сети Wi-Fi, открыть `http://<адрес компьютера>:8000`;
- **на компьютере**: открыть `http://localhost:8000` в Chrome, включить режим устройства в DevTools (Ctrl+Shift+M / Cmd+Shift+M) и выбрать телефон, например iPhone 13. Или открыть `http://localhost:8000/?dev`, тогда игра запустится и в обычном окне.

Сохранения, пройденные концовки и настройки хранятся в браузере.

## Что в репозитории

- `game/` — собранная игра: `index.html` и `assets/` (картинки сцен, значки предметов, заставка, музыка, фоны и звуки).
- `engine/` — код движка:
  - `src/` — разбор сценария и его исполнение (один код для браузера и для проверок);
  - `web/` — страница игры: вёрстка, экраны, WebGL-кадр, звук, мини-игры, заставка;
  - `tools/` — сборка (`build.mjs`), проверка всех веток сценария (`check.mjs`), автопрогон в браузере (`playtest.mjs`);
  - `sample/script/` — небольшой пример сценария для проверки движка;
  - `SCRIPT-FORMAT.md` — формат сценария.

Исходники сценария, рисунков и звука в репозиторий пока не входят, поэтому пересобрать игру из `engine/` нельзя; инструменты рассчитаны на рабочую папку проекта. Играть нужно в готовую сборку из `game/`.

## Версии

Каждая выпущенная версия игры лежит отдельным коммитом с тегом (`v3`, `v4` и дальше). Номер текущей версии записан в `VERSION`; тег ставит GitHub Actions при смене номера.
